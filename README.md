# 搬迁报价台

- 行业：物流（居民 / 公司搬迁）
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

搬家客服把原来的物流费用试算器手工报搬迁价，楼层和大件一多就容易算错。
本项目按**费用规则、保存、页面三层分开**实现，规则只有一处真源。

## 计费规则（`src/pricing.ts`）

纯函数 `calculateQuote(conditions)`，页面试算与确认冻结都走它：

1. **楼层费**：每层 20 元
   - 有电梯且电梯直达入户层：不收楼层费；
   - 有电梯但电梯不到入户层：只算入户层与电梯到达层之间的步行楼层；
   - 无电梯：按步行楼层计（1 层不收）；
   - 起点、终点两侧步行楼层合计计费。
2. **搬运距离费**：车到门口超过 30 米，一次性收 50 元，否则免收。
3. **大件费**：每件 80 元（钢琴、保险柜、大鱼缸等）。

## 业务流程（`src/stores/quoteStore.ts` + `src/storage.ts`）

- 录入起终点、两侧楼层 / 电梯 / 电梯到达层、搬运距离、大件件数后可实时试算；
- **确认后**总额与明细冻结为快照，已确认记录不允许直接改；
- 要改条件请点「改条件另建方案」：条件带入表单，另存为待确认新方案，
  并记录来源，原报价继续可查；
- 待确认方案可以原地修改，也可以再「确认冻结」；
- 数据保存在浏览器 `localStorage`（沿用旧 key `hxwlfront-13-freight`）。

## 旧记录兼容

加载时所有记录先经 `normalizeRecord` 归一化：

- 旧版试算器记录（客户 / 线路 / 重量 / 服务）包装成「旧试算记录」只读展示，
  **缺字段也能打开**，并支持「按此录入新报价」；
- 新版记录缺失或损坏的字段按默认值补齐；已确认记录优先读冻结明细，
  明细缺失时按当前规则补算。
